## รูปแบบ

แต่ละฉบับใช้โครง: บริบท → ทางเลือกที่พิจารณา → การตัดสินใจ → ผลที่ตามมา (ทั้งดีและร้าย)
ADR ที่ไม่บอกข้อเสียของทางเลือกที่เลือก คือ ADR ที่ยังเขียนไม่เสร็จ
